# Start here — GitHub publication checklist

1. Create a GitHub repository named `TRMS-PID-LQR-Control`.
2. Upload the **contents** of this directory to the repository root (not the enclosing folder).
3. Open `README.md` and confirm all relative links and eight figure previews load.
4. Read `docs/10_source_review_notes.md` before claiming the models are executable.
5. Discuss redistribution and licensing with all paper coauthors before making the repository public. Figure 1 is credited to an external source in the manuscript; check reuse permissions.
6. Add verified MATLAB/Simulink files, firmware, and raw data later. No executable source is included in this release.

**Source:** `paper/TRMS_Final_Paper_Senturk_Acar_Deri.pdf` (6 pages). All numerical performance tables in this repository are from the paper.
